# 본노엘 캐릭터·로고 자료

사장님이 2026-10-01에 올려 주신 브랜드 이미지 3개. 다른 작업(명세서, 알림, 로딩 화면, 굿즈 등)에서 쓸 때 여기서 가져다 씀.

- **bonnoel-logo.png** — 본노엘(BON NOËL) 로고. 로즈톤(#af4c60 계열) 배경, 크리스마스트리·종·빵·집 아이콘 4개 + "본노엘 BON NOËL SINCE 2014". `icon-192.png`/`icon-512.png`(앱 아이콘)의 원본.
- **sogeumi.png** — "소금이": 바게트 모양 캐릭터. 흰 요리사 모자(정면에 "BNL"), 분홍 앞치마. 무표정.
- **ppasagi.webp** — "빠삭이": 크루아상/삼각形 빵 캐릭터. 흰 요리사 모자("BNL"), 분홍 앞치마. 말풍선 "빵은 빠삭. 나는 푸석." 아래 3단계 표정 세트: **출근**(밝게 인사) → **멘붕**(식은땀) → **마감**(납작하게 누움, 유령). 직원 피로도를 유머로 표현한 상태 캐릭터로 보임 — 체크리스트·마감 관련 화면의 상태 표시에 어울릴 수 있음.

톤앤매너는 [[본노엘 톤앤매너]] 메모 참고 (로즈톤 #af4c60, Gowun Batang/Noto Sans KR, 둥근 카드).
