# 선결제 매장 POP (A4)

- `prepay-pop-A4.*` — 1차(가영이네 참고 구도, 5% 한 가지)
- `prepay-pop2-5pct-A4.*` — 2차 새 구도, **현재 규칙**(10만원 이상 5% 추가 적립)
- `prepay-pop2-tiered-A4.*` — 2차 새 구도, **구간 적립안**(5만원 이하 0% · 5만원 초과~10만원 미만 7% · 10만원 이상 10%). **앱은 아직 이 규칙을 지원하지 않음**(지금은 기준 금액 1개·비율 1개) — 이 POP를 붙이려면 앱 먼저 구간 적립으로 바꿔야 함.
