# 매장 QR 모음 (2026-10-10)

손님용 QR을 한곳에 모은 것. 인쇄물에는 주소 글자를 넣지 않음(QR 안에만).

| 종류 | 손님이 찍으면 | 매장별? | 개별 POP |
|---|---|---|---|
| 🎁 리뷰 이벤트 | 리뷰 쓰고 빵 뽑기 (`ops ?g=<매장 id>`) | 매장별 | `pdf/QR-POP-리뷰이벤트-A5.pdf` |
| 💌 고객의 소리 | 의견 쓰기 (`ops ?v=<매장 id>`) | 매장별 | `pdf/QR-POP-고객의소리-A5.pdf` |
| 🥚 알레르기 정보 | 빵 검색·"○○ 없는" 필터 (`www /b/`) | 4매장 같음 | `pdf/QR-POP-알레르기-A5.pdf` |
| 💳 선결제 | 이용 안내·잔액 조회 (`ops prepay.html`) | 4매장 같음 | `pdf/QR-POP-선결제-A5.pdf` |
| 🌏 외국어 메뉴 | 폰 언어 맞춤 메뉴판 (`www /qr/<매장>`) | 매장별 | `pdf/QR-POP-외국어메뉴-A5.pdf` |

- **종합 한 장**: `pdf/QR모음-A4.pdf` (매장별 4쪽, QR 5개). 매장이 좁으면 이것 한 장만 붙여도 됨.
- 개별 POP PDF는 종류마다 4쪽(성수·답십리·중계·왕십리 순). A5라 계산대 아크릴 꽂이에 맞음.
- 미리보기 그림: `png/`. 모든 QR은 그림에서 다시 읽어 주소가 맞는지 확인함(10/10).
- 빵마다 붙이는 QR 스티커(`/b/?id=`)는 상품 옆용이라 여기 없음 → `bonnoel-web/print/qr/bread/`.
