# 직원 구매 (직원 할인) 설계 — 2026-09-19

## 왜
- 직원이 빵을 사면 할인해 주는데, 영수증을 톡방에 올리고 사장님이 하루 마감 때 손으로 합을 냄 → 번거로움
- 누가 샀는지, 어느 지점인지 구분이 안 됨 (영수증에 손글씨로 매장·이름을 적고 있음)

## 할인 규칙 (전 매장 공통)
| 결제 방식 | 할인 |
|---|---|
| 현금, 계좌이체, 카카오페이 | 30% |
| 카드, 서울페이, 온누리상품권 | 20% |
| 현금인데 현금영수증 발행 | 20% (세금이 나라에 잡혀서 카드와 같음) |

## 사장님 결정 (2026-09-19)
- 방식: 앱에 "직원 구매" 메뉴 추가 (톡방 대체. 남겨 둬도 됨)
- 마감 합 = 할인 총액 + 실제 낸 금액 **둘 다**
- 입력은 **산 직원 본인**이 자기 폰에서 (매장·이름은 로그인으로 자동)
- 영수증 **사진 필수** (증빙)

## 화면
| 주소 | 누가 | 내용 |
|---|---|---|
| `#/buy` | 모두 | 사진 찍기 → 자동 읽기(날짜·정가·할인·낸 금액·결제 방식·매장·산 것) → 확인 → 저장. 결제 방식/정가를 바꾸면 할인·낸 금액 자동 계산. 영수증 할인율과 고른 결제 방식이 다르면 빨간 경고. 아래에 "내 이번 달 구매" (오늘 올린 건 본인이 지울 수 있음) |
| `#/buy-list/{all 또는 지점}/{YYYY-MM}` | 사장님·매니저 | 월 합계(건·정가·할인·낸 금액) → **날짜별**(마감용, 오늘이 맨 위) → **사람별**. 줄을 누르면 고치기·삭제·사진 보기. CSV |
| 홈 | 사장님·매니저 | "오늘 직원 구매 N건 · 오늘 할인 합계 X원 (낸 금액 Y원)" 요약 |

매니저는 자기 매장만, 사장님은 전체 + 매장 탭.

## 데이터 (supabase-migration-staffbuy.sql)
- `ops_staff_purchases`: bought_on, staff_id, branch_id, pay_method, discount_rate(그때 적용한 %), list_total(정가), discount, paid, items, memo, photo_path, ocr
- 사진은 카드 지출과 같은 `receipts` 버킷, 경로 `staff/매장/월/파일.jpg`

## 자동 읽기
- 기존 `read-receipt` 함수에 `kind: "staff_purchase"`를 추가 (같은 함수, 프롬프트만 다름) → 함수 코드를 한 번 다시 붙여넣어 배포해야 함
- 예전 함수(법인카드용)가 그대로 배포돼 있어도 동작: 결제 금액만 읽어 와서 정가 = 낸 금액 ÷ (1 − 할인율)로 계산
- 함수가 없거나 실패해도 직접 입력으로 저장 가능

## 안 하는 것 (이번엔)
- 지난 톡방 영수증 소급 입력
- 할인율을 앱에서 바꾸는 설정 화면 (규칙이 바뀌면 코드의 BUY_METHODS 표만 고침. 옛 기록엔 그때 할인율이 저장돼 있어 안 바뀜)
- 직원별 월 한도·경고

## 2026-09-20 추가 (사장님 요청)
- **사진 없이 직접 입력**: API 키(자동 읽기)에 돈 안 쓰기로 함 → 사진 필수를 없애고 "사진 없이 직접 입력" 링크 추가(영수증 올리기와 같은 방식). 사진은 있으면 증빙으로 남지만 이제 선택.
- **베이커 등 앱에 없는 사람도 구매자로 기록**: 사장님이 대신 입력할 때 "구매한 사람" 목록(select)이 등록된 알바만 있어서 베이커는 못 골랐음 → 이름을 자유롭게 쓰는 칸으로 바꿈(등록된 직원 이름은 자동완성). `ops_staff_purchases.buyer_name`에 저장, 등록된 사람이면 `staff_id`도 같이 맞춰짐.
- **누가 입력했는지 vs 누가 샀는지 구분**: `entered_by`(실제 입력한 사람, 대부분 사장님) 컬럼 추가. 화면에는 항상 **실제 구매자**(`buyer_name` 우선, 없으면 등록된 이름)만 보임 — 대신 입력한 사람 이름은 안 보임. `#/buy`의 "내가 이번 달에 넣은 구매"는 이제 `entered_by` 기준(사장님이 남 대신 넣은 것도 여기서 보임).
- **홈 화면**: "오늘 직원 구매" 요약 밑에 오늘 산 사람들을 "지점 이름 · 지점 이름 ..." 한 줄로 바로 보여줌(최대 6명, 클릭 안 해도 누가 샀는지 바로 앎).
