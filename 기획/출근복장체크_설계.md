# 출근 복장 체크 설계 (PRD)

> **새 앱이 아니라 기존 매장폰 출퇴근(`#/clock`)에 덧붙이는 기능.** 이름·비밀번호, 근무표 기준 인정 시간, 자동 퇴근, 추가 근무 올리기는 지금 그대로 두고, [출근하기]와 실제 출근 기록 사이에 복장 체크 화면 하나만 끼워 넣는다.

## 왜
오토 매장이라 사장님이 매장마다 복장을 직접 볼 수 없음. 10/8에 보니 복장을 지키지 않은 사람이 꽤 많았음.
→ **매장폰에서 출근을 누를 때 복장을 하나씩 체크해야 하고, 다 체크해야 출근이 찍히게** 한다.
출근 시각이 곧 인정 시작이므로(12차 규칙: 근무표 시작보다 늦게 찍으면 지각 차감), 복장을 다 갖추고 와야 제시간에 출근이 된다.

## 체크 항목
| 항목 | 누가 | 통과 조건 |
|---|---|---|
| 앞치마 | 모두 | 착용 |
| 유니폼 | 모두 | 착용 |
| 마스크 | 모두 | 착용 |
| 이름표 | 모두 | 착용 |
| 머리망 | **전원** (매니저·사장님이 제외로 확정한 사람만 빠짐) | 착용 |
| 모자 | 모두 (질문으로) | "모자 안 씀" 또는 "회사 모자 씀" → 통과 / "개인 모자 씀" → **막힘** |

- 모자는 체크칸이 아니라 버튼 3개: [모자 안 씀] [회사 모자] [개인 모자]. 개인 모자를 누르면 "개인 모자는 벗거나 회사 모자로 바꿔 주세요"가 뜨고 출근 버튼이 안 눌림.
- 항목 목록은 사장님이 설정에서 바꿀 수 있게 `ops_settings`에 저장 (나중에 "위생 장갑" 같은 항목 추가 대비).

## 흐름 (매장폰 `#/clock`)
1. 이름 → 비밀번호 (지금과 같음)
2. [출근하기]를 누르면 바로 출근이 아니라 **복장 체크 화면**이 열림
3. 큰 카드(그림 + 글씨)를 입는 순서대로 하나씩 눌러 체크. 다 체크하기 전엔 맨 아래 버튼이 회색.
   - 물건이 없을 때(이름표 분실, 마스크 다 씀 등): 카드 아래 작은 글씨 [없어요] → 사유 한 줄(필수) → 그 항목은 "없음"으로 넘어감. 출근은 되고 사장님·매니저 화면에 **빨간 글씨**로 표시(예: "이름표 없음: 분실").
   - [없어요]를 누르면 화면에 크게 안내: **"매니저님에게 즉시 연락해주세요."** (출근 완료 메시지에도 한 번 더 표시)
   - 개인 모자는 [없어요]로 넘길 수 없음(벗으면 되므로).
4. [복장 다 갖췄어요 · 출근] → **이 순간의 시각이 출근 시각**. 이후는 지금 흐름 그대로(근무표 복사, 자동 퇴근).

- 퇴근 때는 체크 없음.
- 사장님(owner)은 체크 없음(지금도 출근 안 눌러도 됨).
- "근무표대로 채우기"(깜빡한 근무 나중에 채움)는 복장 체크를 할 수 없으니 기록에 "복장 확인 없음"으로 남김.

## 머리망 대상 관리
- **전원 대상이 기본.** 성별은 저장하지 않음. 직원마다 "머리망" 칸 하나만 둔다:
  - `required` 대상 (모든 직원 기본값)
  - `exempt` 제외 확정 — **누가, 언제, 왜** 제외했는지 같이 저장
- **매니저가 바로 제외 (확정 방식)**: 매니저·사장님이 직원 화면(또는 출근 현황의 이름)에서 [머리망 제외] → 사유 한 줄 → **누르는 순간 확정, 그 뒤로 매일 자동 적용.** 매일 다시 누를 필요 없음.
  - 제외 취소도 같은 자리에서 [머리망 다시 대상으로] (머리가 길어진 경우).
- **직원 예외 신청**: 복장 체크 화면의 머리망 카드 아래 작은 글씨 [머리망 예외 신청] → 사유 한 줄 → 매니저·사장님 화면에 "머리망 예외 대기". 매니저·사장님이 [승인] 하면 위와 똑같이 제외 확정(그 뒤 매일 적용) / [거절]. **승인 전까지는 머리망 체크를 해야 출근됨.**

## 매니저·사장님 화면
- 홈 "지금 출근 현황"에 이름 옆 복장 표시: ✓(다 체크) / 빨강("없어요"로 넘긴 항목과 사유).
- 사진은 받지 않으므로 체크가 사실인지는 매니저가 매장에서 보거나 CCTV로 확인. 체크했는데 실제로 안 지켰으면 근무 조회·출근 현황에서 **[복장 지적]** → 무엇이 빠졌는지 고르기 + 한 줄 메모.
- 이번 주 "없어요" 건수도 같이 보여 줌(같은 사람이 자주 넘기면 바로 보이게).
- 월별 "복장 지적" 누적을 직원별로 보기 (평가·면담 자료).

## 누가 무엇을 보나 (10/8 사장님 결정)
- **모두**(알바·매장폰·매니저·사장님): 홈 "출근 복장 체크" 칸, `#/dress` 화면 보기, [👀 미리 보기](기록 안 남음, 연습/본 시행 화면 전환).
- **매니저·사장님만**: 머리망 제외·다시 대상, 예외 신청 승인·거절, 복장 지적. 본 시행일 변경은 사장님만.
- **실장 계정**(사장님 테스트용): 근무표 없어도 매장폰 [출근하기]로 복장 체크, 출근 기록 안 남음.

## 시행 순서
1. 직원 공지 (시행일, 항목, 머리망은 전원 착용·예외 신청 방법, 물건이 없으면 매니저님에게 즉시 연락)
2. **연습 1주**: 체크 화면은 나오지만 빠뜨려도 출근은 됨, 빠뜨린 항목만 기록 (결정 3)
3. 본 시행: 다 체크해야 출근

## 데이터
(1차 구현 10/8 — 새 표 없이 열 3개만 추가: `supabase-migration-dress.sql`)
- `ops_attendance`: `dress_check` jsonb (예: `{"apron":true,"uniform":true,"mask":true,"nametag":false,"hairnet":true|"exempt","hat":"company"}`), `dress_missing` jsonb ("없어요"로 넘긴 항목과 사유, 연습 기간에 빠뜨린 항목 — 예: `[{"item":"nametag","reason":"분실"}]`), `dress_flag` jsonb (매니저 지적 `{memo, by, at}`)
- `ops_settings` key `dress`: `{ enforce_from: 'YYYY-MM-DD', hairnet_exempt: { 직원id: {by, at, note} }, hairnet_req: { 직원id: {reason, at} } }` — 기본 본 시행일 2026-10-16, 사장님이 `#/dress`에서 변경
- 화면: 매장폰 `#/clock` [출근하기] → 복장 체크, 매니저·사장님 `#/dress` (홈 "출퇴근 관리"에 "출근 복장 체크" 칸)
- 항목 목록은 1차에선 코드에 고정(`DRESS_ITEMS`). 설정에서 바꾸기는 나중.

## 주의 (노무사 확인 권장)
- **옷 갈아입는 시간**: 회사가 의무로 입게 하는 유니폼 착용 시간은 근로시간으로 볼 수 있다는 판례가 있음. 이 기능은 "복장을 다 갖춘 시각 = 출근"이라, 근무표 시작 전에 미리 와서 갈아입게 하면 그 시간이 무급이 됨. → 공지에는 "근무 시작 시각에 복장 갖추고 출근 찍기"까지만 쓰고, 일찍 오라고 강요하는 문구는 피하기.

## 1차에 안 하는 것
- 거울 사진 (사장님 결정 10/8: 체크만. 거짓 체크가 많으면 그때 다시 검토)
- 퇴근 때 복장 체크
- 카톡·문자 알림

## 사장님 결정 (10/8)
1. **거울 사진 없음** — 체크만.
2. **물건이 없을 때** — [없어요] + 사유 쓰면 출근되고 사장님·매니저 화면에 빨간 표시. (개인 모자는 예외: 벗어야 출근)
3. **연습 1주 뒤 본 시행** — 연습 기간엔 빠뜨려도 출근되고 기록만.
4. **머리망은 전원 대상** — 매니저·사장님이 [머리망 제외]를 누르면 바로 확정되고 매일 적용(매일 다시 누르지 않음). 직원이 직접 예외 신청도 할 수 있고, 매니저·사장님 승인으로 확정.
5. **[없어요] 안내 문구** — "매니저님에게 즉시 연락해주세요."
6. **기존 출퇴근 기능에 추가** — 새 앱·새 메뉴가 아님.
