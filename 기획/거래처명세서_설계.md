# 거래처 납품 · 월 명세서 설계 (2026-09-30)

## 왜
우디집·파랜드·앤드밀·카멜 납품 기록을 매니저가 엑셀에 적고, 사장님이 월초에 지난달 명세서를 거래처에 보냄.
엑셀이 거래처마다 모양이 다르고 수식이 깨지기 쉬움(카멜 9월 시트 `#REF!`). → 운영 앱 모듈로 옮김.

## 사장님 결정 (9/30)
- 본노엘 운영 앱에 넣음 (별도 앱 아님)
- 입력은 **성수**에서 전부 (성수 매장폰·매니저 + 사장님)
- 명세서는 **카톡으로 이미지/PDF** 전송
- 단가는 **거래처마다 1개로 고정** (우디집·파랜드 = 현금가)
- 더하고 빼는 것: 택배비(+)·택시비(−)·반품·할인(−)
- 입금 확인도 앱에서: 덜 들어오면 다음 달 "전달 미입금"으로 자동 이월
- 지난 엑셀 기록은 안 옮김. 10/1부터 앱 입력, 9월분은 엑셀로 마무리

## 화면
| 주소 | 누가 | 하는 일 |
|---|---|---|
| `#/vd/날짜` 납품 입력 | 성수 매장폰·매니저·사장님 | 날짜 → 거래처·납품처·품목 개수 (칸 벗어나면 자동 저장), 택배비·택시비 |
| `#/vd-month/YYYY-MM` | 위와 같음 | 엑셀처럼 날짜 × 품목 한 달 표 |
| `#/vs/YYYY-MM` 거래처 명세서 | 사장님 | 기본 = 지난달. 거래처별 금액·상태(안 보냄/보냄/일부 입금/입금 완료) |
| `#/vs-v/거래처id/YYYY-MM` | 사장님 | 미리보기 → 이미지·PDF 공유 → [보냈어요]로 금액 고정 → 입금일·금액 |
| `#/vset` 거래처 설정 | 사장님 | 거래처·납품처·품목·단가·사용 여부, 명세서 머리글·입금 계좌 |

## 계산
- 줄 금액 = 반올림(한 달 개수 합 × 단가)
- 합계 = 납품 금액 + 추가·차감 + 전달 미입금(지난달 명세서 합계 − 들어온 금액)
- [보냈어요] 누르면 계산 결과를 `ops_vendor_statements.snapshot`에 그대로 저장 → 단가를 바꿔도 보낸 명세서는 안 변함. 보낸 뒤 기록이 바뀌면 빨간 안내 + [보냄 취소]로 다시 계산

## 표 (`supabase-migration-vendor.sql`)
`ops_vendors` · `ops_vendor_sites` · `ops_vendor_items` · `ops_vendor_deliveries`(날짜+납품처+품목 한 줄) · `ops_vendor_extras`(부호 포함 금액) · `ops_vendor_statements`(거래처+월 한 줄) · `ops_settings.vendor_stmt`(머리글·계좌)
