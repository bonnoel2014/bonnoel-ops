# 카드 지출 (법인카드 영수증) 설계 — 2026-09-19

## 왜
- 영수증을 카톡에 올려도 합산이 안 되고, 카드 대금이 빠져나가도 "그런가 보다" 하게 됨
- 지점(성수·왕십리·중계·답십리)마다 얼마 썼는지 구분이 안 됨

## 사장님 결정 (2026-09-19)
- 법인카드 약 8장. 지점마다 카드가 따로 있음 → 카드 끝 4자리로 지점 자동 구분
- 사장님 기명카드 1장은 모바일(사장님)과 실물(성수점)이 같은 번호 → 올릴 때 "공통(사장님)/성수" 선택
- 사진은 각 지점 매니저·직원이 앱에서 직접 올림
- 앱에 사진을 올리면 자동으로 가게명·날짜·금액·카드 끝자리를 읽음 (Claude, Supabase Edge Function)
- 카드사 명세서 붙여넣기 대조까지 같이
- 분류 항목: 식자재 / 포장재 / 비품·소모품 / 수리·설비 / 공과금·통신 / 식대·회식 / 차량·교통 / 기타
- 지점은 올리는 사람이 고름(카드로 자동 제안). 자동 읽기는 가게명·금액·날짜·카드만
- 결과: 월별·지점별·항목별 합계 + 목록 + CSV
- 이번 달부터 새로 쌓음. 원본 사진은 Supabase 저장소(receipts 버킷)에 보관

## 화면
| 주소 | 누가 | 내용 |
|---|---|---|
| `#/expense` | 모두 | 영수증 올리기: 사진 → 자동 읽기 → 카드·지점·항목 확인 → 저장. 사진 없이 직접 입력도 가능 |
| `#/expense-list/{지점 또는 all, common}/{YYYY-MM}` | 사장님·매니저 | 월별 목록, 수정·삭제, 사진 보기 |
| `#/expense-sum/{YYYY-MM}` | 사장님·매니저 | 지점×항목 합계표, 카드별 합계, CSV |
| `#/expense-import/{YYYY-MM}` | 사장님·매니저 | 카드사 명세서 붙여넣기 → 일치 ✓ / 금액 다름 / 영수증 없음 → 바로 등록 |
| `#/expense-cards` | 사장님 | 카드 끝 4자리·이름·지점·"쓰는 사람 여럿" 설정 |

## 데이터 (supabase-migration-expense.sql)
- `ops_cards`: last4, name, branch_id(null=공통), ask_branch(올릴 때 지점 물어봄), active
- `ops_expenses`: spent_on, merchant, amount, card_id, card_last4, branch_id(null=공통), category, memo, photo_path, ocr(jsonb), source(receipt/statement), statement_key(명세서와 맞춰진 표시), uploaded_by
- 저장소 버킷 `receipts` (비공개, 서명 URL로 봄)

## 자동 읽기 (supabase/functions/read-receipt)
- 앱이 사진을 1600px로 줄여 base64로 보냄 → 함수가 Claude에게 JSON으로 읽어 달라고 함 → {merchant, spent_on, amount, card_last4, summary}
- API 키는 함수 비밀(Secrets)에만 둠. 앱에는 안 들어감
- 함수가 없거나 실패해도 직접 입력으로 저장 가능

## 안 하는 것 (이번엔)
- 지난 카톡 영수증 소급 입력 (원하면 사진을 Claude에게 주고 읽어서 넣음)
- 세무사 전달용 월 마감 요약 문서 (CSV로 대신)
