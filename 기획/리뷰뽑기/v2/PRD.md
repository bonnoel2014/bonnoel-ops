# 기획안(PRD) — 리뷰 뽑기판 (디지털 뽑기) · v2

> 초안 — v1을 더 써 보고 확정 (10/4 매장 반응 테스트 반영)

- 가게 / 이름: 본노엘 / 손성필
- 주제(영역): 손님 응대 · 리뷰 이벤트 운영
- 이 버전의 목표 한 줄: 아이 손님은 게임하듯 뽑고(확률·기록은 그대로), 사장님은 이벤트로 나간 빵을 돈으로 보는 도구

## 1. 무엇을 왜 만들고 싶나요?

10/4 매장에서 종이 뽑기판과 매장폰 뽑기판을 손님에게 같이 내밀어 봤더니, 어른은 종이판을, 아이들은 패드·게임하듯 폰으로 뽑는 걸 좋아했다. 종이판은 곧 없앨 예정이라 아이들이 더 좋아할 "게임" 방식이 필요하다. 등수는 지금처럼 서버가 520알 확률로 정하고, 게임은 보여 주는 연출만 바꾼다(실력 게임은 넣지 않는다 — 잘했는데 5등이면 속은 느낌).

또 v1으로 뽑기와 기록은 되지만, "이벤트에 한 달 얼마가 드는지"는 아직 사장님이 머릿속으로 곱해야 한다. 1등 충전금은 직원이 선결제 쪽에서 따로 적립해야 하고, 일일 보고서에도 뽑기 숫자가 빠져 있다.

## 2. 누가 언제 쓰나요?

- 손님(특히 아이): 직원이 건넨 매장폰에서 "뽑기판 / 게임" 중 하나를 골라 뽑는다.
- 사장님: 월말에 비용 보기. 상품 단가 입력. 어떤 방식이 인기인지 보기.
- 매장 매니저: 오늘 품절인 등수 끄기.
- 직원: 1등 충전금 자동 적립 때 확인 버튼.

## 4. 도구를 쓰면 어떤 일이 달라지나요?

시작 화면에서 직원이 "손님께 건네기"를 누르면 손님이 뽑는 방법(뽑기판 / 캡슐 뽑기 / …)을 고르고, 어느 방법이든 결과·지급·취소는 지금과 똑같다. 기록에 "어떤 방법으로 뽑았는지"가 남아 사장님 현황에서 방법별 횟수가 보인다. 사장님 현황에 금액 줄이 생기고, 1등이 나오면 결과 화면에서 "충전금 적립" 확인 한 번으로 선결제에 들어가며, 일일 보고서에 "오늘 뽑기 N번" 한 줄이 자동으로 붙는다.

## 5. 이번 버전에서 만들 것

**꼭 할 것**
- 게임 모드 1개 — 빵 캡슐 뽑기(가챠): 손잡이를 돌리면 캡슐이 떨어지고 두드려 열면 등수. 시작 화면에 "뽑는 방법 고르기"(뽑기판 / 캡슐), 뽑기 기록에 방법(method) 칸 추가, 사장님 현황에 방법별 횟수. 소금이·빠삭이 캐릭터(bonnoel-ops/assets/characters) 사용.
- 이벤트 비용 환산: 상품별 단가(원가 또는 판매가) 입력 → 사장님 현황에 매장별 월 비용 표시.
- 1등 선결제 충전금 자동 적립: 성수·중계·답십리 1등 결과 화면에 "충전금 30,000 적립" 버튼 → 직원이 손님 번호 확인 후 누르면 선결제 모듈에 적립. 준비물: 선결제 DB 함수에 "이벤트 적립" 사유 추가, 적립 기록이 뽑기 기록과 연결.

**여유 있으면**
- 게임 모드 추가 (반응 보고 하나씩): 소금이 집게 뽑기(크레인) → 오븐 열기(빠삭이가 굽고 아이가 문 열기) → 스크래치 복권(어른도 좋아함).
- 디지털 뽑기판에 뜯는 애니메이션·종이 소리(어른 손맛 보완).
- 품절 등수 잠그기: 매니저가 오늘 품절 등수를 끄면 그 칸이 나와도 다음 등수 상품을 안내하고 기록에 남김.
- 일일 보고서 합계: 기존 일일 보고서에 "오늘 뽑기 N번 · 1등 N" 한 줄.
- 리뷰 출처 기록: 뽑기 시작 때 네이버/카카오맵/구글 선택, 현황에 채널별 수.

**이번에 하지 않을 것:** 손님 폰 QR 뽑기 · 리뷰 삭제 감시 (나중)

## 6. 완성됐다는 걸 어떻게 확인하나요?

- 시연할 예시 입력: 손님이 "캡슐 뽑기"를 골라 손잡이 돌리기 → 캡슐 열기 → 등수 → 지급 완료 · 단가 5개 입력 후 성수점 10월 집계 보기 · 성수점 1등 뽑힘 → 충전금 적립 버튼.
- 기대하는 결과: 캡슐로 뽑은 기록이 방법=캡슐로 남고 사장님 현황에 "뽑기판 N · 캡슐 N"이 보임 · 성수 10월 비용 금액이 표시됨 · 선결제 쪽에 "이벤트 적립 30,000"이 기록되고 뽑기 기록에도 "적립 완료" 표시.
- 잘못 입력했을 때: 단가 비면 그 상품은 "단가 없음"으로 금액 제외 · 적립 버튼 두 번 눌러도 한 번만.
- 다시 열었을 때 남아 있어야 할 것: 단가표, 적립 연결 기록, 품절 설정.
