# 전체 기획안(PRD) — 리뷰 뽑기판 (디지털 뽑기)

- 가게 / 이름: 본노엘 / 손성필
- 주제(영역): 손님 응대 · 리뷰 이벤트 운영
- 한 줄 목표: 매장 직원이 손님이 리뷰를 보여 주는 순간에, 매장폰 화면의 뽑기판으로 등수를 뽑고 상품 지급까지 기록하는 도구
- 마지막 수정: 2026-10-03

> **이 문서는 "다 만들었을 때의 모습"입니다.** 먼저 여기에 전체를 그린 뒤, 4번 기능 목록에 꼬리표를 붙여
> 오늘 만들 것은 `v1/PRD.md`로, 나중에 더할 것은 `v2/PRD.md`로 나눕니다.
> v1을 써 본 뒤에는 `v1/사용메모.md`를 보고 이 문서와 v2를 다시 고칩니다.

## 1. 배경 — 최근 실제로 있었던 한 장면

- 장면: 손님이 계산하면서 "리뷰 쓰면 뽑기 되나요?" 하거나 직원이 안내한다 → 손님이 그 자리에서 네이버 영수증 리뷰(별점 5개 · 사진 1장 이상 · 저장) 또는 카카오맵·구글 리뷰를 쓰고 폰 화면을 직원에게 보여 준다 → 직원이 확인하고 벽에 붙은 종이 뽑기판(520알)을 내밀어 한 알 뽑게 한다 → 등수를 보고 매장 등수표에 적힌 빵을 꺼내 준다.
- 막히는 곳:
  - 뽑기판을 매달 새로 사야 하고(매장당 한 판 1~2만원), 쓰다 보면 뜯긴 자국으로 지저분해진다.
  - 1등이 나왔는데 그 빵이 품절·마감이면 직원이 임의로 다른 걸 주고, 뭘 줬는지 남지 않는다.
  - 몇 등이 몇 번 나갔는지 집계가 없어서 이벤트로 빵이 얼마나 나가는지 모른다.
  - 알바가 바뀌면 참여 조건·진행 방법 안내가 직원마다 다르다.
- 얼마나 자주: 매장당 하루 4~10번 (4매장 합치면 한 달 500~1,200번)
- 한 번에 걸리는 시간: 1~2분 [가정]
- 실수·빠뜨림: 품절 시 대체 지급이 기록 없이 나감 · 등수별 지급 집계 0

## 2. 쓰는 사람과 역할

| 누가 | 언제 여나 | 무엇을 보나 | 무엇을 누르나 | 어떤 기기로 |
|---|---|---|---|---|
| 매장 직원(알바 포함) | 손님이 리뷰를 보여 줄 때 | 참여 조건 체크, 결과 등수·상품 (횟수·남은 알 같은 숫자는 안 보임) | 뽑기 시작, 지급 완료, 다른 걸로 드림, 취소(매장 코드) | 매장폰 |
| 손님 | 직원이 매장폰을 건넬 때 | 520칸 뽑기판 | 칸 하나 눌러 뒤집기 | 매장폰(건네받음) |
| 매장 매니저 | 상품 구성이 바뀔 때 | 우리 매장 1~5등 상품표 | 상품 문구 수정 | 매장폰 |
| 사장님 | 월말·수시 | 매장별 월 당첨 집계, 판 진행 상황, 이벤트 비용 (집계는 사장님만 봄) | 상품표 수정, 새 판 시작, 상품 단가 입력 | 사장님 앱(폰) |

## 3. 흐름 — 지금 vs 도구를 쓰면

| 단계 | 지금 (쓰는 앱·파일) | 도구를 쓰면 |
|---|---|---|
| 1 | 직원이 말로 참여 조건 안내 (종이 안내문) | 매장폰 뽑기 화면에 참여 조건이 떠 있고, 직원이 체크(별점 5 · 사진 · 저장)하고 "뽑기 시작" |
| 2 | 손님이 벽 뽑기판에서 한 알 뜯음 | 손님이 매장폰에서 칸 하나를 눌러 뒤집음 (이미 뽑힌 칸은 비어 보임) |
| 3 | 알 펼쳐서 등수 확인, 등수표 보고 빵 꺼냄 | 화면에 등수와 우리 매장 상품이 바로 뜸 |
| 4 | 지급하고 끝 (기록 없음) | 직원이 "지급 완료" 또는 "다른 걸로 드림(뭐 줬는지)" 누름 → 기록이 남음 |
| 5 | 판 다 뜯기면 새 판 사 와서 붙임 | 520알 다 뽑히면 자동으로 새 판 시작 |
| 6 | (없음) | 사장님 앱에서 매장별 월 집계·판 진행·비용 확인 |

## 7. 예외 — 잘못 넣거나 평소와 다를 때

- 당첨 상품이 품절·마감이면 → 직원이 "다른 걸로 드림"을 누르고 뭐 줬는지 적는다. 기록에 "4등 → 대체: 마들렌 2개"로 남는다.
- 손님이 칸을 두 번 누르면 → 첫 칸이 뒤집히는 순간 판 전체가 잠겨 두 번째는 눌리지 않는다.
- 리뷰 확인 전에 뽑혔거나 실수로 뽑혔으면 → 직원이 매장 코드로 취소. 알은 판으로 돌아가고 취소 기록은 남는다.
- 520알이 다 뽑히면 → 자동으로 새 판이 시작되고, 사장님 현황에 "성수 2번째 판 시작(10/3)"으로 보인다.
- 사장님이 "새 판 시작"을 누르면 → "남은 알 300개가 있는데 새 판을 시작할까요?" 확인 뒤 지금 판을 닫는다. 닫힌 판의 기록은 그대로 남는다. 직원이 뽑는 도중이면 그 뽑기는 옛 판으로 끝낸 뒤 새 판이 적용된다.
- 매장폰·매니저 화면에는 당첨 횟수·남은 알 같은 숫자가 보이지 않는다 → 직원이 "1등 아직 남았어요?" 물어도 화면으로는 알 수 없다.
- 저장이 안 됐으면(인터넷 끊김 등) → 결과를 보여 주기 전에 저장이 되어야 한다. 저장 실패면 "다시 눌러 주세요" 안내, 알은 줄지 않는다.
- 상품표가 비어 있는 매장이면 → 뽑기 시작이 막히고 "상품표를 먼저 채워 주세요" 안내.
- 같은 손님이 하루에 두 번 하려 하면 → 도구는 손님을 구별하지 않는다. 직원이 눈으로 거른다(사람 몫).

## 8. 사람이 꼭 직접 해야 하는 것 (자동화 금지)

- 리뷰 조건 확인(별점 5 · 사진 · 저장)은 직원이 손님 폰을 보고 판단한다. 도구는 체크칸만 준다.
- "지급 완료" · "다른 걸로 드림" · "취소"는 직원이 누른다.
- 상품표 변경은 사장님·매니저만. 판 교체(새 판 시작)는 사장님만.
- 1등 선결제 충전금 지급은 v1에서는 직원이 선결제 쪽에서 직접 처리한다. v2에서 자동 적립을 붙여도 직원 확인 버튼을 거친다.

## 9. 성공 기준 — 숫자로

- 지금: 뽑기판 구매 매장당 월 1~2만원(4매장 4~8만원) · 등수별 지급 집계 0 · 대체 지급 기록 0
- 목표: 뽑기판 구매 0원 · 매장별 월 집계 100% · 대체·취소 전부 기록 · 직원 교체 때 추가 설명 없이 진행
- 시연할 예시 입력 → 기대하는 결과: 성수점에서 뽑기 5번(그중 1번은 "다른 걸로 드림", 1번은 취소) → 뽑기 기록 5건(지급 3·대체 1·취소 1), 판 남은 알 516, 사장님 현황에 성수 이번 달 5번·등수별 수가 바로 반영

## 11. 아직 정하지 못한 것

- 성수점 등수표: 종이에는 2등 "포인트 20,000(?)"과 6등·7등(마들렌)까지 보임. 화면 판은 5등까지라 성수점 1~5등 상품을 다시 정해야 함.
- 중계점 3등 "파운드 1조각"인지 "1개"인지 사진이 흐림.
- 한 번에 걸리는 시간 1~2분 [가정]. 써 보고 고침.
- 화면 판으로 바꾸는 날, 벽에 남은 종이판은 그대로 소진하고 끝낼지, 바로 뗄지.
- 매장 코드로 취소할 때 매장폰에 이미 로그인된 매장 코드를 다시 묻는 게 번거로우면 "길게 누르기"로 바꿀지.
- 리뷰 출처 기록을 v1에 넣을지(버튼 하나 더 느는 대신 채널별 효과가 보임).
- 매니저에게도 판 남은 알 정도는 보여 줄지(지금은 사장님만).
