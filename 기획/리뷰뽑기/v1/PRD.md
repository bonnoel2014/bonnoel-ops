# 기획안(PRD) — 리뷰 뽑기판 (디지털 뽑기) · v1

- 가게 / 이름: 본노엘 / 손성필
- 주제(영역): 손님 응대 · 리뷰 이벤트 운영
- 이 버전의 목표 한 줄: 매장 직원이 손님이 리뷰를 보여 주는 순간에, 매장폰 뽑기판으로 등수를 뽑고 지급까지 기록하면 사장님 앱에 매장별 집계가 쌓이는 도구

## 1. 무엇을 왜 만들고 싶나요?

매장 4곳(성수·왕십리·중계·답십리)에서 "리뷰 쓰면 추억의 뽑기판" 이벤트를 하고 있다. 손님이 네이버 영수증 리뷰(별점 5 · 사진 1장 이상 · 저장)나 카카오맵·구글 리뷰를 보여 주면 벽에 붙은 종이 뽑기판(520알)에서 한 알 뽑고, 등수에 맞는 빵을 준다.
불편한 것: 뽑기판을 매달 새로 사야 하고(매장당 1~2만원) 쓰다 보면 지저분해진다. 당첨 빵이 품절이면 직원이 임의로 다른 걸 주고 기록이 안 남는다. 몇 등이 몇 번 나갔는지 집계가 없다. 알바가 바뀌면 안내가 직원마다 다르다.

## 2. 누가 언제 쓰나요?

- 매장 직원: 손님이 리뷰를 보여 줄 때 매장폰에서 연다. 참여 조건 체크 → 손님에게 폰 건넴 → 결과 보고 지급 버튼. 횟수·남은 알 같은 숫자는 보이지 않는다.
- 손님: 건네받은 매장폰에서 칸 하나를 눌러 뒤집는다.
- 매장 매니저: 우리 매장 1~5등 상품 문구가 바뀔 때 수정한다.
- 사장님: 사장님 앱에서 매장별 월 집계와 판 진행 상황을 본다(사장님만). 상품표 수정과 "새 판 시작"도 사장님이 한다.

매장당 하루 4~10번. 4매장 합치면 한 달 500~1,200번.

## 3. 지금은 어떻게 하고 있나요?

1. 직원이 말로(종이 안내문) 참여 조건 안내
2. 손님이 그 자리에서 리뷰 쓰고 폰 화면 보여 줌
3. 직원이 확인하고 벽 뽑기판에서 한 알 뜯게 함
4. 알 펼쳐 등수 확인, 매장 등수표(손글씨·인쇄) 보고 빵 꺼내 줌
5. 기록 없음. 판 다 뜯기면 새로 사 와서 붙임

## 4. 도구를 쓰면 어떤 일이 달라지나요?

한 건 기준: 직원이 매장폰에서 조건 3개 체크 후 "손님께 건네기" → 손님이 520칸 중 하나를 눌러 뒤집기 → 등수와 우리 매장 상품이 뜸 → 직원이 "지급 완료" 또는 "다른 걸로 드림(뭐 줬는지)" → 기록 저장, 판에서 그 알이 줄어듦.
사장님 앱에는 매장별 이번 달 횟수·등수별 지급·대체·취소 수와 판 남은 알이 바로 보인다. 520알이 다 뽑히면 새 판이 자동으로 시작된다.

## 5. 이번 버전에서 만들 것 (v1이면 하루 안에 되는 것만)

- 기능 1 · 매장별 가상 뽑기판: 매장마다 520알(1등 1 · 2등 3 · 16 · 100 · 400). 뽑히면 그 등수가 하나 줄고, 다 뽑히면 자동 새 판.
- 기능 2 · 뽑기 화면(매장폰): 참여 조건 체크 3개 → 손님께 건네기 → 520칸 판(뽑힌 칸은 빈 자국) → 한 칸 누르면 판 잠기고 등수·상품 표시.
- 기능 3 · 지급 기록: 결과 화면에서 "지급 완료" / "다른 걸로 드림 + 뭐 줬는지". 저장돼야 결과를 보여 준다.
- 기능 4 · 취소: 직원이 매장 코드 입력 후 취소. 알은 판으로 돌아가고 취소 기록은 남음.
- 기능 5 · 매장별 상품표: 1~5등 상품 문구, 사장님·매니저가 수정. 비어 있으면 뽑기 시작이 막힘.
- 기능 6 · 사장님 현황(사장님 앱, 사장님만 보임): 매장별 이번 달 집계표(횟수·등수별·대체·취소), 매장별 판 남은 알과 1등 남았는지, 달 바꾸기.
- 기능 7 · 사장님 판 교체: 사장님 현황에서 매장별 "새 판 시작" 버튼. 남은 알이 있어도 확인 한 번 뒤 지금 판을 닫고 520알 새 판. 닫힌 판의 기록은 남음.
- 초기 상품표(사진 기준, 성수점은 11번 미정 사항 확인 후 수정):
  - 왕십리: 1등 식빵(대)+파운드+마들렌 · 2등 식빵(대) · 3등 파운드 · 4등 휘낭시에 · 5등 마들렌
  - 성수: 1등 선결제 충전금 30,000 · 2등 (확인) · 3등 러스크 1봉 · 4등 휘낭시에 1개 · 5등 파운드 1개
  - 중계: 1등 선결제 충전금 30,000 · 2등 러스크 1봉 · 3등 파운드 1조각(확인) · 4등 휘낭시에 1개 · 5등 마들렌 1개
  - 답십리: 1등 선결제 충전금 30,000 · 2등 러스크 1봉 · 3등 휘낭시에 1개+마들렌 1개 · 4등 파운드 1개 · 5등 마들렌 1개
- **이번에 하지 않을 것:** 이벤트 비용 환산 · 품절 등수 잠그기 · 일일 보고서 합계 · 1등 선결제 충전금 자동 적립 · 리뷰 출처 기록 (이상 v2) · 손님 폰 QR 뽑기 · 리뷰 삭제 감시 (나중)

## 6. 완성됐다는 걸 어떻게 확인하나요?

- 시연할 예시 입력: 성수점 매장폰에서 뽑기 5번. 그중 1번은 "다른 걸로 드림(마들렌 2개)", 1번은 매장 코드로 취소.
- 기대하는 결과: 뽑기 기록 5건(지급 3 · 대체 1 · 취소 1). 성수 판 남은 알 516(취소된 1알은 복귀). 사장님 현황에 성수 이번 달 5번과 등수별 수가 바로 보임. 매장폰에는 숫자가 안 보임. 사장님이 성수 "새 판 시작" → 남은 알 520, 집계 5번은 그대로.
- 잘못 입력했을 때: 칸을 두 번 눌러도 첫 칸만 뒤집힘 · 저장 실패면 결과를 안 보여 주고 "다시 눌러 주세요", 알은 안 줄어듦 · 상품표 빈 매장은 뽑기 시작 불가 안내 · 취소는 매장 코드 틀리면 안 됨.
- 다시 열었을 때 남아 있어야 할 것: 매장별 판 남은 알(등수별), 뽑기 기록 전부(매장·시각·등수·상품·상태·대체 상품), 매장별 상품표.

## 7. 다음 버전에서 더할 것 (v2: API·외부 데이터 등)

- 다음에 추가할 기능 하나: 이벤트 비용 환산(상품 단가 × 월 집계).
- 필요한 데이터나 외부 연결: 상품 단가 등록 · 선결제 모듈의 적립 함수(1등 충전금 자동 적립) · 일일 보고서 양식.
- 사람이 직접 판단·확인해야 할 부분: 충전금 적립은 자동이어도 직원 확인 버튼을 거침. 품절 등수 잠그기는 매니저가 켜고 끔.

## 8. 절대 자동화하면 안 되는 것

- 리뷰 조건 확인(별점 5 · 사진 · 저장)은 직원이 손님 폰을 보고 판단. 도구는 체크칸만.
- "지급 완료" · "다른 걸로 드림" · "취소"는 직원이 누른다.
- 상품표 변경은 사장님·매니저만. 새 판 시작은 사장님만.
- 선결제 충전금 지급은 v1에서 직원이 선결제 쪽에서 직접 처리.
