# 본노엘 "법인 통장 자금 흐름" 기획안 (PRD 초안)

작성: 2026-09-26 · 상태: **1차 범위 확정 (10번 참고)** (`[가정]` 표시는 아직 확인 안 된 것)

---

## 1. 왜 만드나 (문제)

- 법인 통장이 **4개**라서, 돈이 어디서 들어와 어디로 나갔는지 한눈에 안 보인다.
- 통장끼리 돈을 옮기면(예: 수입 통장 → 급여 통장) 한쪽에선 "나감", 다른 쪽에선 "들어옴"으로 찍혀서 **실제보다 많이 쓰고 많이 번 것처럼** 보인다. ← 헷갈리는 가장 큰 이유로 추정 `[가정]`
- 알고 싶은 것:
  - 어디에 얼마를 썼나
  - 카드 대금이 얼마 나갔나 (카드사별)
  - 배민·쿠팡이츠 입금이 얼마 들어왔나
  - 4대보험이 얼마 나갔나
  - 그래서 이번 달 **돈이 늘었나 줄었나**, 다음 달엔 모자라지 않나

## 2. 목표 (한 줄)

> **통장 4개를 "하나의 회사 지갑"처럼 본다.**
> 한 달에 한 번 거래내역 엑셀만 올리면, 들어온 돈·나간 돈이 항목별로 자동 정리되고, 통장끼리 옮긴 돈은 빠진다.

## 3. 어디에 만드나

- **기존 운영 앱(ops.bonnoel.com) 안에 사장님만 보이는 새 폴더 "자금"** (확정)
  - 이유: 카드 지출(영수증), 급여명세서, 선결제, 매출 기록이 이미 앱에 있어서 **서로 맞춰 보기(대조)** 가 가능하다.
  - 통장 거래내역은 민감한 정보 → 사장님 계정만 읽고 쓸 수 있게 잠금(RLS). 매니저·알바 화면에 절대 안 나옴.
  - 실제 거래내역 파일·금액은 GitHub에 올리지 않는다(코드만 올라감).
- 다른 방법: 매출분석처럼 **내 컴퓨터 엑셀 + 대시보드** (사장님 폰에서 못 봄)

## 4. 돈이 들어오는 방법 (데이터 넣기)

| 방법 | 설명 | 추천 |
|---|---|---|
| **A. 인터넷뱅킹 엑셀 올리기** | 은행 사이트에서 "거래내역 조회 → 엑셀 저장" → 앱에 올림. 은행마다 양식이 달라도 앱이 알아서 읽음 | ✅ 1차 |
| B. 자동 연동 | 유료 금융 API(예: 코드에프 등)로 매일 자동 수집. 월 사용료·법인 공동인증서 등록 필요 | 3차에 검토 |
| C. 캡처 사진 | 화면 캡처를 Claude가 읽음 | 엑셀이 안 될 때만 |

- 같은 거래를 두 번 올려도 **중복 저장 안 됨** (날짜+시각+금액+잔액으로 구분)

## 5. 자동 분류 (핵심)

거래내역의 "적요/받는 분/보낸 분" 글자를 보고 자동으로 항목을 붙인다. 사장님이 한 번 고치면 **다음부터는 그 규칙대로** 붙는다.

| 큰 항목 | 작은 항목 (예) | 알아보는 단서 (예) |
|---|---|---|
| 💰 **매출 입금** | 배민 정산 / 쿠팡이츠 정산 / 카드 매출(카드사 입금) / 현금 입금 / 선결제 | 우아한형제들, 쿠팡이츠, 카드사 가맹점 입금 |
| 💳 **카드 대금** | 카드사별 (국민·신한·현대 등) | ○○카드 결제 |
| 👥 **인건비** | 급여 / 4대보험 / 퇴직연금 | 직원 이름 이체, 국민건강보험공단, 국민연금공단, 근로복지공단 |
| 🏠 **고정비** | 월세 / 관리비 / 전기·가스·수도 / 통신 / 보험 / 리스·렌탈 | 임대인, 한전, 도시가스, KT·SKT |
| 🥐 **재료·물품** | 식자재 / 포장재 / 비품 (계좌이체로 낸 것) | 거래처 이름 |
| 🧾 **세금** | 부가세 / 원천세 / 법인세 / 지방세 | 세무서, 위택스 |
| 🏦 **금융** | 대출 원금 / 이자 / 수수료 | 은행 이름 |
| 🔁 **통장끼리 이동** | 계산에서 **빠짐** | 우리 통장 4개 번호끼리 오간 돈 → 자동 인식 |
| ❓ **미분류** | 사장님이 확인 | — |

- 매장 구분: **통장이 매장별로 하나씩**이라 어느 통장 거래인지로 매장이 자동으로 정해진다. 매장끼리 돈을 옮긴 건 회사 전체 합계에선 빠지고, 매장별 화면에선 "다른 매장으로 보냄/받음"으로 따로 보인다

## 6. 단계별로 만들 것

### 1차 — "이번 달 돈이 어디로 갔나" (먼저 만들 것)

| # | 기능 | 설명 |
|---|---|---|
| 1 | **통장 설정** | 통장 4개 = 매장 4곳(성수·왕십리·중계·답십리). 은행·끝 4자리만 등록 |
| 2 | **거래내역 올리기** | 엑셀 올리기 → 미리보기 → 저장. 중복 자동 제외 |
| 3 | **자동 분류 + 미분류 정리** | 모르는 거래만 모아서 보여 줌 → 항목 고르면 규칙 저장 |
| 4 | **월 자금 흐름표** | 들어온 돈 / 나간 돈 / 남은 돈(증감). **통장끼리 이동은 제외.** 항목별 합계 + 지난달과 비교. **회사 전체 ↔ 매장별** 전환 |
| 5 | **질문별 바로 보기 카드** | "카드 대금 얼마?" "배민·쿠팡 입금 얼마?" "4대보험 얼마?" "급여 총액?" — 홈에서 숫자 하나씩 |
| 6 | **통장별 잔액** | 통장 4개 마지막 잔액 + 합계(회사 전체 현금) |
| 7 | **엑셀 내려받기** | 세무사 전달용 (월별 항목 합계 + 전체 목록) |

**성공 기준:** 월초에 엑셀 4개 올리고 **10분 안에** "지난달 들어온 돈·나간 돈·항목별 금액"이 나온다. 미분류가 첫 달 30개 이하, 둘째 달부터 5개 이하. `[가정]`

### 2차 — "맞춰 보기" (앱에 이미 있는 기록과 대조)

| 기능 | 무엇과 무엇을 맞추나 | 찾아 주는 것 |
|---|---|---|
| **카드 대금 대조** | 통장에서 빠진 카드 대금 ↔ 카드 지출(영수증) 합계 | 영수증 안 올린 지출 규모 |
| **배민 입금 대조** | 통장에 들어온 배민 돈 ↔ 배민 정산명세서 입금 예정액 | 덜 들어온 돈, 입금 늦은 날 |
| **급여 대조** | 급여 이체 합계 ↔ 급여명세서 실지급액 | 이중 이체·빠진 사람 |
| **4대보험 추이** | 달마다 4대보험 금액 ↔ 직원 수 | 퇴사자 상실신고 누락 의심 |

### 3차 — "다음 달 돈이 모자라지 않나" + 더 나아가기

| 기능 | 설명 |
|---|---|
| **돈 나가는 달력** | 매달 정해진 날 나가는 돈 자동 표시 (예: 10일 4대보험·원천세, 카드 결제일, 월세일, 부가세 1·4·7·10월 25일 `[확인 필요]`) |
| **잔액 예측·부족 알림** | "이 속도면 ○일에 급여 통장 잔액이 모자라요" → 미리 옮길 금액 제안 |
| **매장별 간이 손익** | 매장 매출(POS·배달) − 매장 비용(재료·인건비·월세·카드) = 매장별로 남는 돈 |
| **이상 지출 알림** | 평소보다 30% 넘게 늘어난 항목, 처음 보는 거래처 큰 금액 |
| **자동 연동** | 유료 API로 매일 자동 수집 (비용·보안 검토 후) |

- 데이터: **은행 엑셀 올리기**로 시작 (자동 연동은 3차에 검토)

## 11. 아직 필요한 것

- 샘플: 통장 1개의 한 달 거래내역 엑셀 (은행 양식 확인용, GitHub에 안 올림)
- 4개 통장의 은행 이름 (은행마다 엑셀 양식이 달라서)
- 매장 통장 말고 급여·카드 대금·4대보험이 어느 통장에서 나가는지 (한 통장에서 몰아서 내는지)

## 12. 샘플 확인 결과 (2026-09-26, 1~7월 거래내역 5개)

실제 금액·이름은 여기 적지 않는다. 확인된 **모양과 규칙**만 적는다.

- 통장은 **5개**: 성수·왕십리·중계·답십리 신한 + **답십리 국민**(카드 매출이 들어오는 통장 → 모아서 답십리 신한으로 옮김). 기업은행 2개(성수·답십리)는 거래가 없어 제외
- 엑셀 양식 2가지면 충분: **신한**(거래일시·적요·입금액·출금액·내용·잔액) / **국민**(위에 6줄 정보 + 거래일시·보낸분/받는분·출금액·입금액·잔액·적요)
- **통장끼리 이동 자동 찾기 검증됨**: 한 통장 출금 = 다른 통장 입금(같은 금액, 5분 안)으로 짝을 맞추면 대부분 잡힌다
- 자동 분류 단서 (실제 거래로 확인):
  - 배민 = 내용 "음식배달" · 쿠팡이츠 = "쿠팡페이" · 카드 매출 = 카드사 약자+번호(KB·SHC·현·하나·삼성·롯데·NH·BC) 또는 적요 "가맹입금/매출표" · 간편결제 = 서울페이·제로페이·Npay·카카오페이·스마트스토어
  - 급여 = 적요 "BZ급여" · 4대보험 = 내용 "○○○○사회보험"(적요 보험료) 또는 적요 연금/의보 · 국세 = "국세납부" · 지방세 = "서울시지방세"
  - 카드 대금 = 내용 "신한카드/신한카드법인/신한법인결제" — **답십리 신한 통장에서만** 나감
  - 전기 "한국전력공사/FB전기", 수도 "수도", 관리비 "…입주", 세무·노무 수수료 자동이체
  - 적요 "유동CC/타행CC" + 사람 이름 = 월세로 추정 `[확인 필요]`
- 규칙만으로 금액 기준 **약 95% 자동 분류**, 나머지는 사람 이름으로 보낸 이체(BZ뱅크) → 미분류 정리 화면에서 한 번씩 고르면 됨
- 확인 필요: 관계사로 보이는 다른 회사로 나간 큰 금액, 파일에 없는 다른 본노엘 통장으로 나간 돈
