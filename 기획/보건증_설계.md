# 보건증 만료 관리 (8차) 설계

## 왜
요식업은 전 직원 보건증(건강진단결과서)이 필수인데 1년마다 갱신이라 잊기 쉬움. 지금은 구글 시트 "근무자 현황"의 마지막 열에 만료일만 적어 두어서, 인명부 폴더를 열어 확인해야 함. 시트는 잠겨 있어 앱이 자동으로 읽을 수 없음(401) → 앱을 보건증 장부로 삼고, 시트 내용은 붙여넣기로 한 번 옮김.

## 화면
- `#/health` (모두): 내 만료일·남은 날짜, 상태 배지, 새 보건증 사진 올리기(만료일은 알면 입력) → 상태 "제출". 내 기록.
- `#/health-admin` (사장님·매니저, 사장님은 매장 탭): 퇴사자 제외 전 직원을 급한 순서로. 이름 누르면 열림 → 제출 사진 열기 + 만료일 + **완료** / 반려(지움), 만료일 직접 넣기, 기록(사진·지움). 맨 아래 "구글 시트에서 가져오기" 붙여넣기 → 읽어 보기 → 이대로 저장.
- 홈: 매니저 요약 숫자(급함 / 두 달 이내 / 제출 확인). 로그인·매장폰 이름표에 빨간 글씨("보건증 없음 / 만료 / D-12"), 제출해 둔 사람은 빨간 글씨 안 보임.

## 규칙
- 빨강: 만료됨, 30일 이내, 보건증 없음. 노랑: 60일 이내. (`HC_RED`, `HC_YELLOW`)
- 현재 만료일 = confirmed 기록 중 가장 늦은 expires_on. submitted 기록이 있으면 "제출 · 확인 대기" 배지.
- 시트 붙여넣기: 머리글(지점·이름·보건증 만료일)이 있으면 그 열, 없으면 시트 원래 순서(지점 다음 7번째 칸). 날짜는 `27.07.03`·`2027.3.19`·`2027-03-19` 모두 읽음. 주민번호·전화·주소·이메일은 읽지도 저장하지도 않음. 앱에 없는 이름은 체크로 직원 추가. 앱 날짜가 같거나 더 최신이면 건너뜀.

## 데이터
- `ops_health_certs`: staff_id, expires_on, status(submitted/confirmed), photo_path, source(sheet/app/manual), submitted_by, confirmed_by, confirmed_at, memo. 이력 보존.
- 사진: `documents` 버킷 `health/{staffId}/{ts}.jpg` (버킷 허용 형식에 image/jpeg 추가).
- 씨앗 없음: 실명이 들어가므로 SQL에 넣지 않고 앱의 시트 붙여넣기로 넣음.

## 나중에
- 카톡·문자 알림(사장님 결정: 나중), 시트 자동 동기화(시트를 서비스 계정에 공유해야 해서 보류).
