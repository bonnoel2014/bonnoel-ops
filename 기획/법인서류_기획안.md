# 본노엘 "법인 서류·법인 관리" 기획안 (PRD 초안)

작성: 2026-09-26 · 상태: **1차 구현 완료 (9/26) — SQL 실행·메일 함수 재배포 대기**

---

## 1. 왜 만드나 (문제)

- 해외여행 중에 외부에서 **주주명부·재직증명서**를 내야 했는데, 노트북이 없어서 못 만들고 세무사에게 부탁했다.
- 법인은 개인사업자보다 **챙겨야 할 서류·기한이 훨씬 많다** (주주명부, 임원 임기, 주총 의사록, 노사협의회 등). 놓치면 과태료가 **대표 개인**에게 나온다.
- 직원 70명 · 다점포라 재직증명서·경력증명서 요청이 계속 들어온다. 지금은 사장님이 한글/워드로 하나씩 만든다.
- 같이 AI 공부하는 사장님들(개인사업자)에게 **"법인이 되면 이런 것까지 자동화된다"** 는 데모가 되고 싶다.

## 2. 목표 (한 줄)

> **휴대폰 하나로, 어디서든(해외 포함) 3분 안에 회사 서류를 만들어 보낸다.**
> 그리고 법인이 놓치기 쉬운 기한은 앱이 먼저 알려준다.

## 3. 어디에 만드나

- **기존 운영 앱(ops.bonnoel.com) 안에 새 폴더 "법인"** 으로 추가한다.
  - 이유: 직원 이름·입사일(`manual_staff.hire_on`)·소속 매장·근로계약서·급여 기록이 **이미 거기 다 있다**. 재직증명서는 그걸 읽기만 하면 된다.
  - 이미 있는 PDF 만들기(근로계약서)·메일 보내기(send-document 함수) 기능을 **그대로 재사용**한다.
- 주주명부·법인 서류함은 **사장님만** 보인다. (매니저·알바 화면에 안 나옴)

## 4. 단계별로 만들 것

### 1차 — "해외에서도 서류 3분" (먼저 만들 것)

| # | 기능 | 누가 | 설명 |
|---|---|---|---|
| 1 | **재직증명서** | 직원 신청 → 사장님 승인(또는 사장님 바로 발급) | 이름·생년월일·입사일·소속·직위를 자동으로 채움. 용도(은행 제출용 등)만 고르면 PDF. 법인 직인 이미지 찍힘. 직원 메일로 자동 발송 + 사장님 참조 |
| 2 | **경력증명서** | 퇴사자 요청 시 사장님 | 재직증명서와 같은 틀, 퇴사일·담당 업무 추가 |
| 3 | **주주명부** | 사장님만 | 주주·주식 수·지분율을 한 번 입력해 두면, "기준일"만 골라 PDF. 상법 352조 필수 항목(성명·주소·주식 종류와 수·취득일) 포함. 지분이 바뀌면 이력으로 남음 |
| 4 | **법인 서류함** | 사장님만 | 사업자등록증, 법인등기부등본(최근본), 정관, 법인인감증명서 사본, 통장 사본, 주주명부 최신본을 한 곳에 보관. **"기간 제한 링크"** (예: 3일 뒤 자동 만료)로 거래처·은행·세무사에게 바로 전달 |
| 5 | **발급 대장 + 진위 확인** | 자동 | 발급할 때마다 발급번호(예: BN-2026-0042)·날짜·용도·받은 사람 기록. PDF 아래 QR → 받는 쪽이 "진짜 본노엘이 발급한 서류인지" 확인하는 페이지 |

**해외 시나리오 (성공 기준)**
공항/호텔에서 폰으로 ops.bonnoel.com → 법인 → 주주명부 → 기준일 오늘 → [PDF 만들기] → [메일로 보내기] (받는 사람 주소 입력) → 끝. **노트북·세무사 없이 3분 이내.**

> 참고: 법인등기부등본·법인인감증명서 "원본"은 법원이 발급하는 거라 우리 앱이 만들 수 없다. 대신
> - 등본은 **인터넷등기소 앱**에서 폰으로 발급 가능 (2023.12부터 모바일 발급 서비스)
> - 우리 앱에는 "최근 받은 사본"을 보관해 두고, 앱 안에 **"인터넷등기소 앱에서 발급하는 법" 바로가기**를 둔다.

### 2차 — 70명 회사의 "법으로 꼭 갖춰야 하는 장부"

상시근로자 수에 따라 법이 요구하는 것이 늘어난다. 본노엘은 30인·50인 기준을 이미 넘는다.

| 기능 | 근거 | 앱이 하는 일 |
|---|---|---|
| **근로자명부** | 근로기준법 41조 (모든 사업장) | 직원 정보에서 자동 생성, 퇴사 후 3년 보관 |
| **임금대장** | 근로기준법 48조 | 이미 있는 급여명세서 기록을 월별 대장 형태로 모아 PDF/엑셀 |
| **연차 관리대장** | 근로기준법 60~61조 | 입사일 기준 연차 자동 계산, 사용 기록, **연차 사용 촉진 통지** 시기 알림 |
| **노사협의회** | 근로자참여법 (30인 이상) | 분기 1회 회의 알림, 회의록 양식, 3년 보관. 미운영 시 벌금 대상 |
| **법정의무교육 체크** | 성희롱 예방(연1회), 개인정보, 장애인 인식개선(모든 사업장), 산업안전 | 직원별 이수 여부 체크 + 이수 안 한 사람 목록 |
| **안전보건 기록** | 중대재해처벌법 (5인 이상 전면 적용) | 매장별 위험성평가·안전점검 체크리스트를 기존 체크 기능처럼 기록 |

### 3차 — "법인 달력" (대표가 과태료 안 맞게)

| 기한 | 앱 알림 |
|---|---|
| **임원(이사·감사) 임기 만료** | 이사 임기 최대 3년. 만료 후 **2주 안에 중임등기** 안 하면 대표 개인에게 과태료(최대 500만 원). 만료 60일·30일·7일 전 알림 |
| **정기 주주총회** | 결산 후 3개월 안. 소집통지서·주총 의사록 양식(재무제표 승인, **임원 보수 한도** 결의 — 임원 급여를 비용으로 인정받는 근거) |
| **세금 기한** | 원천세(매월 10일), 부가세(1·4·7·10월 25일), 법인세(결산 후 3개월 말), 지방소득세 — 세무사에게 넘길 자료 체크리스트 포함 |
| **주식등변동상황명세서** | 법인세 신고 때 같이 제출 → 주주명부 이력에서 자동으로 "올해 바뀐 것" 뽑아 세무사에게 전달 |
| **이사회 의사록·임원 규정** | 임원 보수 규정, 임원 퇴직금 규정 양식 (세무사·법무사 확인 전제) |

### 그 뒤 (아이디어 창고)

- **가지급금 경고**: 법인카드 기록(이미 있음) 중 사적 사용 의심 건을 모아 세무사 확인 요청
- **업무용 승용차 운행기록부**: 법인 차량이 있으면 연 1,500만 원 넘는 비용 인정에 필요
- **매장별 손익 한눈에**: 매출 통합 양식과 연결해 법인 전체 / 매장별
- **정부 지원사업**: 청년지원금(이미 있음) 외 고용 관련 지원금 신청 기한 알림
- **세무사 공유 페이지**: 매달 세무사가 필요한 자료(카드·급여·매출)를 한 링크로

## 5. 다른 사장님 데모용 구분

발표할 때 이렇게 나눠 보여주면 개인사업자 사장님도 따라 할 수 있다.

| 개인사업자도 바로 쓸 수 있음 | 법인만 해당 |
|---|---|
| 재직·경력증명서, 근로자명부, 임금대장, 연차대장, 의무교육 체크, 세금 달력, 서류함 | 주주명부, 주총·이사회 의사록, 임원 임기 알림, 주식변동명세서, 가지급금 |

데모는 `?demo=1` 시연 모드(가짜 회사·가짜 직원)로 보여준다 → **진짜 주주·직원 정보는 화면에 안 나온다.**

## 6. 안전장치 (중요)

- **직인 이미지**: 도장 이미지가 있으면 누구나 서류를 위조할 수 있으니 → 사장님 승인 없이는 직인이 찍힌 PDF가 안 만들어진다. 이미지 파일은 비공개 저장소(사장님만 접근)에 둔다. GitHub(공개)에는 절대 안 올린다.
- **주주명부·서류함**: 사장님 계정만 읽기/쓰기 가능하게 DB 권한(RLS)을 따로 건다.
- **주민등록번호는 앱에 저장하지 않는다** (기존 결정 유지). 재직증명서는 생년월일로. 은행이 주민번호를 꼭 요구하면 "뒷자리 가림" 또는 PDF 만들 때만 입력하고 저장 안 함.
- **공유 링크는 기한 만료** (기본 3일). 누가 언제 열었는지 기록.
- 법률 문구·양식은 **노무사/세무사/법무사 확인 전까지 "초안"** 표시.

## 7. 1차 성공 기준

- [ ] 해외 시나리오: 폰으로 주주명부 PDF 만들어 메일 발송까지 3분 이내
- [ ] 직원이 재직증명서 신청 → 사장님 폰 알림 → 승인 1번 → 직원 메일 도착
- [ ] 발급 대장에 번호·용도·수신자가 남고, QR로 진위 확인 됨
- [ ] 매니저·알바 화면에서는 주주명부·서류함이 안 보임

## 8. 결정된 것 (2026-09-26)

1. 주주명부 맞음. **가족 포함 여러 명** → 주주별 행 + 지분율 합계 100% 검사 필요
2. 재직증명서: **직원 신청 → 사장님 승인** 후 발급·메일
3. 도장: **사용인감(회사 직인) 이미지**. 법인인감은 앱에 안 넣음
4. 1차 범위: 재직·경력증명서, 주주명부, 법인 서류함 + 기한 링크, 발급 대장 + QR 진위확인 (4개 전부)

## 9. 아직 필요한 것

- 주주 명단(이름·주소·주식 수·취득일), 발행주식 총수, 1주 금액 → 사장님만 보는 화면에서 직접 입력 (채팅·GitHub에 안 올림)
- 사용인감 도장 사진(흰 종이에 찍어서 폰 촬영)
- 회사 정식 이름·법인등록번호·본점 주소·대표이사 이름 (재직증명서 머리글)
- (나중에) 결산월, 이사·감사 이름과 취임일, 취업규칙·노사협의회 운영 여부, 법인 차량 유무, 세무사 메일 주소
