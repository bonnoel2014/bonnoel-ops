# 기획안(PRD) — 고객의 소리 ("의견 주세요") · v1

- 가게 / 이름: 본노엘 / 손성필
- 주제(영역): 손님 응대 · 매장 서비스 관리
- 이 버전의 목표 한 줄: 매장에 온 손님이 계산대 QR을 찍어 30초 안에 의견을 남기고, 사장님은 사장님 앱에서 4매장 의견을 보고 답장·처리까지 기록하는 도구

## 1. 무엇을 왜 만들고 싶나요?

사장님이 매장에 늘 있지 않아 손님 불만·칭찬·아이디어가 사장님까지 오지 않는다. 불만은 외부 리뷰로 먼저 터지고, 직원 응대도 느슨해질 수 있다. 손님 목소리가 사장님께 바로 닿는 통로를 만든다.

## 2. 누가 언제 쓰나요?

- 손님: 계산대 POP의 QR을 봤을 때 (매장 안이나 집에서), 자기 폰, 로그인 없음
- 사장님: 사장님 앱(owner.bonnoel.com) 홈 타일에 "새 의견 N"이 보일 때
- 매장 직원·매니저: 의견은 **못 봄**. POP 인쇄만 함

## 3. 지금은 어떻게 하고 있나요?

통로가 없다. 손님이 직원에게 직접 말하거나, 배민·네이버 리뷰로 남기거나, 그냥 넘어간다.

## 4. 도구를 쓰면 어떤 일이 달라지나요?

손님: QR → 칩 하나(😣 불편 · 👏 칭찬 · 💡 아이디어 · 🛠️ 바라는 점 · 💬 기타) → 내용 → (선택) 방문 시간대·이름·번호·답장 받을래요 → 보내기 → 감사 화면
사장님: 의견함에 카드로 쌓임 → 열면 "확인함" → 답장 쓰고 번호 복사·문자 앱으로 직접 보냄 → "답장함" → 메모 → "처리 완료"

## 5. 이번 버전에서 만들 것

- 운영 앱 손님 페이지 `ops.bonnoel.com/?v=<매장 id>` (로그인 없음) — 칩·칩별 안내·방문 시간대·이름/번호(선택)·답장 받을래요·개인정보 동의(이름/번호 남길 때만)
- 장난 막기: 기기당 하루 3건, IP당 하루 10건, 내용 5~1,000자
- 운영 앱 "고객의 소리 POP (QR)" — 매장별 계산대 A4 포스터 (매장폰·매니저·사장님)
- 사장님 앱 "💌 고객의 소리" 타일(새 의견 수) + 의견함(처리 전/완료/숨김 · 매장 · 종류 필터) + 자세히(답장 기록·번호 복사·문자 앱·메모·처리 완료·숨김·지우기) + 1년 지난 이름·번호 지우기
- 데이터 창고: `supabase-migration-voice.sql` (표 voice_feedback, 손님은 voice_submit 함수로 쓰기만, 읽기는 사장님만)
- **이번에 하지 않을 것:** 메일 알림 · 급한 의견 자동 표시 · 사진 첨부 · 직원 칭찬 공유 · 근무표 연결 · 월별 모아 보기 · 테이블·봉투 스티커 · 문자 자동 발송 · 혜택 · AI 분류

## 6. 완성됐다는 걸 어떻게 확인하나요?

- 시연할 예시 입력: 왕십리 QR → 😣 불편했어요 → "포장할 때 빵이 눌렸어요" → 오늘 오후 → 익명으로 보내기
- 기대하는 결과: 감사 화면 + 급한 일 안내 → 사장님 앱 홈 "새 의견 1" → 의견함 "왕십리 · 불편" 카드 → 열면 확인함 → 처리 완료
- 잘못 입력했을 때: 칩 없음 / 5자 미만 / 번호 형식 틀림 / 답장 원함인데 번호 없음 / 이름·번호 넣고 동의 안 함 → 안내하고 안 보내짐. 하루 제한 넘으면 안내
- 다시 열었을 때 남아 있어야 할 것: 의견·상태·답장 문구·메모·처리 시각

## 7. 다음 버전에서 더할 것 (v2)

- 새 의견 메일 알림 또는 아침 브리핑 한 줄, 급한 의견 표시, 칭찬 직원 공유 등 → `../v2/PRD.md`
- 사람이 직접 판단·확인해야 할 부분: 답장 내용, 직원에게 전달할지

## 8. 절대 자동화하면 안 되는 것

- 손님에게 가는 답장 (사장님이 직접 쓰고 직접 보냄)
- 의견을 근거로 한 직원 평가·주의
- 의견·개인정보 삭제
