# 전체 기획안(PRD) — 고객의 소리 ("의견 주세요")

- 가게 / 이름: 본노엘 / 손성필
- 주제(영역): 손님 응대 · 매장 서비스 관리
- 한 줄 목표: 매장에 온 손님이 불편·칭찬·아이디어가 떠오른 순간에, 매장 QR을 찍어 30초 안에 의견을 남기고, 사장님은 사장님 앱에서 4매장 의견을 한곳에서 보고 답장·처리까지 하는 도구
- 마지막 수정: 2026-10-08 (초안 — `[가정]`은 사장님 확인 전 추정)

> **이 문서는 "다 만들었을 때의 모습"입니다.** 4번 기능 목록의 꼬리표로
> 먼저 만들 것은 `v1/PRD.md`로, 나중에 더할 것은 `v2/PRD.md`로 나눕니다.

## 1. 배경 — 왜 필요한가

- 상황: 본노엘은 오프라인 매장 4곳(성수·왕십리·답십리·중계)이고 사장님이 매장에 늘 있지 않다. 손님이 불편을 느껴도 말할 사람이 없거나(직원에게 말하기는 부담), 말해도 사장님까지 전달되지 않는다.
- 장면 [가정]: 손님이 빵을 샀는데 계산이 늦거나 직원 응대가 퉁명스러웠다 → 그 자리에선 아무 말 안 하고 나간다 → 다시 오지 않거나, 배민·네이버에 별점 낮은 리뷰로 남긴다 → 사장님은 리뷰를 보고서야 알고, 언제·누구였는지 알기 어렵다.
- 반대쪽도 있다: 칭찬("직원분이 친절했어요")이나 좋은 아이디어("○○빵 작은 사이즈도 있으면")도 지금은 사라진다.
- 결과: 직원 입장에선 "사장님이 모른다" → 응대가 느슨해질 수 있다. 손님의 목소리가 매장까지 닿는 통로가 하나 있으면, 그 자체로 응대 긴장감이 생긴다.
- 얼마나 자주: 지금은 모은 기록이 0건이라 모름. `[가정]` 매장당 월 5~15건
- 실수·빠뜨림: 불만이 리뷰로 먼저 터짐 · 칭찬받은 직원도 모름 · 손님 아이디어가 기록되지 않음

## 2. 쓰는 사람과 역할

| 누가 | 언제 여나 | 무엇을 보나 | 무엇을 누르나 | 어떤 기기로 |
|---|---|---|---|---|
| 손님 | 매장에서 QR 스티커·POP를 봤을 때 (매장 안 또는 집에 가서) | 의견 종류 칩, 내용 칸, 이름·번호(선택), "답장 받을래요" | 칩 고르기 → 내용 쓰기 → 보내기 | 손님 폰 (로그인 없음) |
| 사장님 | 새 의견이 왔을 때 · 하루 한 번 | 4매장 의견 목록(매장·종류·상태별), 내용, 답장 원하는지 | 확인함 · 답장 기록 · 처리 완료 · 메모 | 사장님 앱(폰) |
| 매장 직원·매니저 | `[가정]` 칭찬만 공유 (11번에서 확정) | 우리 매장에 온 칭찬·건의 일부 | 보기만 | 매장폰 (ops 앱) |

## 3. 흐름 — 지금 vs 도구를 쓰면

| 단계 | 지금 | 도구를 쓰면 |
|---|---|---|
| 1 | 손님이 불편을 느낌 → 말할 곳 없음 | 계산대·테이블·포장 봉투 스티커의 QR "의견 주세요"를 찍음 |
| 2 | 그냥 나가거나 외부 리뷰로 남김 | 어느 매장인지는 QR이 알아서 넣음. 칩으로 종류 고르고 내용 작성 |
| 3 | 사장님은 리뷰를 보고서야 앎 | 사장님 앱에 바로 들어옴(매장·종류·시간 표시) |
| 4 | 손님에게 사과·답할 방법 없음 | 손님이 "답장 받을래요"를 체크했으면 번호가 보이고, 사장님이 답장 |
| 5 | 무엇이 반복되는지 모름 | 처리 상태·메모가 남고, 월별로 매장·종류별 개수를 봄 |

## 7. 예외 — 잘못 넣거나 평소와 다를 때

- 칩을 안 고르고 보내면 → "어떤 의견인지 하나 골라 주세요" 안내, 안 보내짐
- 내용이 너무 짧으면(10자 미만) → "조금만 더 알려 주세요" `[가정]`
- "답장 받을래요"를 체크했는데 번호가 없거나 형식이 틀리면 → 번호 칸 빨간 안내
- 번호를 넣었는데 동의를 안 하면 → 동의를 체크하거나 번호를 지우라고 안내 (익명으로 보낼 수 있음)
- 같은 기기·IP에서 하루 제한을 넘으면 → "오늘은 의견을 충분히 받았어요" 안내
- 욕설·도배 → 저장은 되지만 사장님 목록에서 "숨김" 처리 가능 `[가정]`
- 위생·이물질·알레르기처럼 급한 일이면 → 감사 화면에 "급한 일은 매장 직원에게 바로 말씀해 주세요" 안내 (v2에서 급함 표시)
- QR 주소의 매장이 잘못됐으면 → "매장을 찾을 수 없어요" (매장 고르기로 대체)

## 8. 사람이 꼭 직접 해야 하는 것 (자동화 금지)

- 손님에게 가는 답장 — 사장님이 직접 쓰고 직접 보낸다(초안·복사만 도움)
- 의견을 근거로 직원을 평가·주의 주는 판단 — 사장님이 사실을 확인한 뒤
- 의견 삭제(처리 완료 후 개인정보 지우기 포함) — 사장님이 누름

## 9. 성공 기준 — 숫자로

- 지금: 손님 의견 기록 0건, 불만은 외부 리뷰로 알게 됨
- 목표 `[가정]`: 4매장 합쳐 월 20건 이상 수집 · 답장 원함은 2일 안에 100% 답장 · 새 의견은 3일 안에 "처리 완료"
- 시연할 예시 입력 → 기대하는 결과:
  - 왕십리 QR → 😣 불편했어요 → "포장할 때 빵이 눌렸어요" → 익명으로 보내기 → 사장님 의견함에 "왕십리 · 불편 · 방금" 카드
  - 성수 QR → 👏 칭찬해요 → 번호 + 답장 받을래요 → 사장님 화면에 "답장 원함" + 번호 복사 → 답장함 → 처리 완료
