# bonnoel-ops — 본노엘 운영 앱 (홈 + 비품 재고·발주)

본노엘 베이커리 4개 매장(성수·왕십리·중계·답십리)에서 쓰는 운영 앱입니다.

**앱 주소: https://sungpil-1225.github.io/bonnoel-ops/** (GitHub Pages. main에 push하면 1분 안에 자동 반영) 홈 화면 하나에 아이콘별로 도구가 붙습니다.

- 1차(지금): **홈** · **비품 체크** · **부족·주문** · **도착 확인** · **점간 이동** · **비품 설정** · **직원·비밀번호** + 매뉴얼북·로그북 링크
- 2차(다음): 휴무·대타·근무표 (홈에 "준비 중"으로 자리만 있음)

기획: [기획/전체_기획안.md](기획/전체_기획안.md) · [기획/1차_만들_것.md](기획/1차_만들_것.md)

## 쓰는 법

1. 폰에서 주소를 열고 **매장 → 내 이름 → 비밀번호 4자리**. 처음 들어오는 사람은 그 자리에서 비밀번호를 정합니다. 잊으면 매니저·사장님이 "직원·비밀번호"에서 초기화.
2. **비품 체크** (근무자, 주 1회): 품목마다 지금 있는 수량만 넣고 저장. 안 센 건 비워 둠.
3. **부족·주문** (사장님·매니저): 적정재고보다 모자란 것이 매장별로 뜸. [주문함] 누르고 며칠 걸리는지 넣으면 그 매장 "도착 확인"에 뜸. [카톡용 복사]로 지금 쓰는 단톡방에 붙일 수도 있음.
4. **도착 확인** (근무자): 온 물건이 수량 맞으면 [맞음], 아니면 [틀림 → 실제 수량]. 틀리면 사장님 홈에 빨간 숫자로 뜸 → 사장님이 [처리함].
5. **점간 이동**: 보내는 매장·받는 매장·품목·수량. 받는 매장 "도착 확인"에 뜸.
6. **비품 설정** (사장님·매니저): 매장별 적정재고 숫자, 이 매장에서 안 쓰는 품목 끄기, 품목 추가·이름 고치기.

재고 계산: 마지막 체크 수량 + 그 뒤 도착 확인한 것 − 그 뒤 보낸 것. 부족 = 적정 − 현재 − 오는 중.

## 데이터 창고 (Supabase) — 처음 한 번

매뉴얼북·로그북과 **같은 Supabase 프로젝트**를 씁니다. 직원 명단도 매뉴얼북의 `manual_staff`를 그대로 같이 씁니다 (비밀번호·역할 열만 추가).

Supabase 대시보드 → SQL Editor → New query → [`supabase-setup.sql`](supabase-setup.sql) 전체 복사·붙여넣기 → Run. 한 번만.
왕십리점 종이 비품리스트의 품목 약 60개가 함께 들어갑니다. 적정재고는 앱의 "비품 설정"에서 넣으세요.

`index.html` 안의 Supabase URL과 `anon`/`publishable` 키는 공개되어도 되는 값입니다. **서비스 롤(service role) 비밀 키는 절대 넣지 마세요.**

## 시연 모드

주소 뒤에 `?demo=1`을 붙이면 데이터 창고 없이 가짜 데이터로 눌러볼 수 있습니다. (비밀번호: 사장님 0000 · 매니저 1111 · 알바 F 2222 · 알바 E는 처음)
